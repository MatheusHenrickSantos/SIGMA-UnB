# Modelo relacional

A **Figura 1** abaixo apresenta o modelo relacional do sistema, organizando as principais entidades envolvidas no controle de estoque. O modelo organiza essas informações em tabelas, evidenciando os atributos principais e as relações entre os dados, incluindo a identificação de chaves primárias e estrangeiras.
